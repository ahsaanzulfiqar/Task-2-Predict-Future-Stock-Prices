# Task 2: Stock Price Prediction (Short-Term)

## Overview
This project is part of the AI/ML Engineering Internship tasks at DevelopersHub Corporation. The objective of this task is to predict the next day’s stock closing price using historical stock market data.

## Objective
The main goal of this project is to:
- Load real-world stock market data using Yahoo Finance
- Analyze historical stock trends
- Train a Machine Learning regression model
- Predict future stock closing prices
- Compare actual vs predicted stock prices visually

## Dataset
- Source: Yahoo Finance
- Library Used: yfinance
- Selected Stock: Apple Inc. (AAPL)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- yfinance

## Machine Learning Model
- Linear Regression

## Project Workflow
1. Load historical stock data
2. Perform data preprocessing
3. Select important features:
   - Open
   - High
   - Low
   - Volume
4. Predict next day closing price
5. Train regression model
6. Evaluate predictions
7. Visualize actual vs predicted prices

## Evaluation
The model performance was evaluated by comparing predicted stock prices with actual closing prices using visualization techniques.

## Key Insights
- Historical stock prices can be used to estimate short-term future trends.
- Regression models can learn relationships between stock features and closing prices.
- Visualization helps understand prediction performance effectively.

## Conclusion
This project demonstrates the practical application of Machine Learning in financial forecasting using real-world stock market data.
